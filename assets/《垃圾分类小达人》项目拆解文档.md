# 《垃圾分类小达人》项目逐条拆解文档

> 依据已提供的 5 个源文件（index.html / data.js / app.js / learn.css / learn.js）逐条整理。
> 说明：`index.html` 第 9 行引用的 `styles.css` **未被提供、且 assets 目录中不存在**，故本文件不臆造其内容，详见「六、缺口与风险」。

## 一、项目概况

| 项 | 内容 |
|---|---|
| 项目名 | 垃圾分类小达人（ShangGongCheng-Game-v1） |
| 形态 | 纯前端离线单页应用（HTML + CSS + 原生 JS），可本地直接打开 |
| 第三方库 | `assets/lib/three.min.js`（跑酷 3D 视角渲染） |
| 字体 | 在线引入 `miaoda.feishu.cn` 的 ZCOOL KuaiLe / Noto Sans SC |
| 语言/编码 | `lang="zh-CN"`，UTF-8 |
| 入口 | `index.html` → 依次加载 `assets/lib/three.min.js` → `data.js` → `app.js` → `learn.js` |

### 文件职责
| 文件 | 行数 | 职责 |
|---|---|---|
| `index.html` | 535 | 全部页面骨架（6 个视图 + 6 个侧边面板 + 全局浮层） |
| `data.js` | 545 | 默认配置 `DEFAULT_CONFIG`（四大玩法全部数值/题库/文案）+ 编辑提示 `EDIT_HINTS` |
| `app.js` | 6893 | 主逻辑：音效 SFX、配置/存档、账号、四大玩法、商城、历史、编辑、管理员 |
| `learn.js` | 438 | 「垃圾分类小课堂」独立模块（IIFE，依赖 app.js 全局环境） |
| `learn.css` | 294 | 小课堂视图样式（糖果风） |
| `styles.css` | 6602 | 全局主样式表：皮肤变量、顶栏/按钮、垃圾桶与物品卡、面板、飞行棋/跑酷/消消乐、加载动画、响应式（含 R12~R68 迭代样式） |

### localStorage 存档键（app.js）
- `trashGameConfigV1`：管理员编辑后的配置
- `trashGameStateV1`：当前用户状态
- `trashGameAccountsV1`：所有账号
- `trashGameCurrentUserV1`：当前用户名
- `trashAdminUnlockedV1`：管理员解锁标记
- 管理员密码哈希常量：`ADMIN_PASS_HASH = 'h1gdps4m'`

## 三、交互清单

### 首页

- 玩法卡片 `#module-pick`（classic / flychess / runner / matches）：切换选中；进入对应玩法前显示封面 `#module-cover`（`#btn-cover-start` 确认开始 / `#btn-cover-back` 返回选模式）
- 题量 `#btn-round-size`（循环切换题量，`#round-size-label` 显示）
- 重置积分 `#btn-reset-home` / `#yellowbox-reset`
- 继续游戏 `#btn-continue` / 重置进度 `#btn-reset-round`（`#pending-round` 上一局进行中提示）

- 四个分类标识 `.mark-item.is-learn`（可回收/厨余/有害/其他）→ 直接进入对应小课堂

## 四、玩法规则与数值（默认配置）

### 1) 小达人（config.settings / settingsExtra）
- 单局题量 `roundSize = 8`（可 4~12）
- 答对得分 `pointsPerCorrect = 10`
- 答错扣分 `settingsExtra.wrongDeduct = 5`
- 单账号局数限制 `classicRoundLimit = 0`（0=不限）

### 2) 垃圾分类飞行棋（config.flychess）
- 棋盘格数 `cellCount = 28`（蛇形路径，四角放四类标识）
- 名次积分 `rankPoints = [30,20,10,5]`（第1~4名）
- 题库 `questions`：25 题，每题 `{q, opts(4选), ans(0~3), itemId}`；每次掷骰后答一题，答对前进、答错原地
- 支持 2~4 人；`FC_SIZE=7`（7×7 棋盘）；单账号限制 `perAccountLimit = 0`

### 3) 垃圾分类跑酷（config.runner）
- 默认时长 `duration = 60s`；吃对 `goodPoints = 10`，吃错 `badPoints = 5`
- 目标切换间隔 `targetChangeMs = 8000ms`；速度倍率 `speed = 0.7`
- 三条轨道 `RT_LANES=[0.16,0.5,0.84]`；3D 第一视角（three.js）
- 难度 `levels`：简单(60s/奖励10/封顶速4)、普通(75s/20/6)、困难(90s/30/8)、超级困难(120s/50/11)、自由模式(无积分,maxSpeed=null)
- 动作图 `actions`：run / power / good / bad / finish

### 4) 垃圾消消乐（config.matches）
- 棋盘 `rows×cols = 6×6`；消除一格 `perMatch = 10`
- 关卡 `levels`：简单(达标300/120s/奖励10)、普通(600/120s/20)、困难(900/150s/30)、超级困难(1500/180s/50)、自由(无积分)
- 每难度最多领奖 `maxRewards = 5`
- 道具各 2 次（提示/置换/洗牌）

### 5) 小课堂 / 考考你（config.learn）
- 内容依据《上海市生活垃圾分类投放指南》
- 四分类 intro：名称、别名、颜色、标识、定义、常见物品、投放贴士
- 易混淆 `tricky`（大骨头/贝壳/榴莲壳/粽叶/玉米芯/无汞干电池→其他；玉米棒→厨余）
- 考考你题池 `quiz`（28 条）；`pointsPerCorrect = 10`，`questionCount = 5`，`perAccountLimit = 0`

### 6) 积分 / 称号 / 限制（通用）
- 称号段位 `badges`（按 min 升序）：环保小卫士(0)、小先锋(200)、小达人(500)、大师(1000)、之星(2000)、大使(5000)
- 共享模块接口（app.js 冻结签名）：`canPlayModule` / `moduleCount` / `bumpModuleCount` / `playCount` / `bumpPlayCount` / `moduleScore` / `addModuleScore` / `recordModuleBest` / `resetModuleScore` / `isAdminUnlocked`

### 7) 音效（SFX）
WebAudio 合成的 `tone/noise/bgmTick`，含点击/正确/错误音与各页面 BGM（home/learn 等）；`#sfx-switch`、`#r65-sound-toggle` 控制开关。

## 五、数据模型（DEFAULT_CONFIG 主要字段）

- `bins`：4 类垃圾桶 `{id,name,color,desc,mark}`
  - 可回收物 #3B82F6 / 厨余垃圾 #8B5E3C / 有害垃圾 #E5484D / 其他垃圾 #3D3A37
- `items`：24 个垃圾物品 `{id,name,img,bin,points,q:{q,bin}}`（四模式共用同一物品池）
- `mall`：6 件商品 `{id,type,name,desc,price,icon,img,maxBuys}`
- `settings`：roundSize / pointsPerCorrect / classicRoundLimit / badgeTitle / heroTitle / heroSub / steps
- `settingsExtra`：wrongDeduct
- `avatar`：name / img / cheer / oops / dialogues（引导员形象与台词）
- `loadingTips`：加载页知识文字
- `loading`：title / animation{enabled,setCount} / runnerEgg{enabled}
- `home`：redBoxLines / randomTitle / randomCta / randomModules
- `moduleNames` / `moduleIntros`：四玩法名称与简介
- `corner`：enabled / img / text / scale（上海工程技术大学水印）
- `titleImg`：顶部标题图标
- `flychess` / `runner` / `matches`：三大玩法配置（见上）
- `learn`：intro / tricky / quiz / tips / pointsPerCorrect / questionCount / perAccountLimit
- `badges`：称号段位表
- `EDIT_HINTS`：编辑面板每项尺寸/格式标注（点分路径 + `[]` 通配）

## 六、缺口与风险

1. **`styles.css` 已补齐（原缺口已关闭）**
   - `index.html` 第 9 行 `<link rel="stylesheet" href="styles.css">` 引用该文件；初版仅提供 5 个文件时该文件缺失，现已按原样补充。
   - 现况：`styles.css`（6602 行 / 239222 字节）已 1:1 还原至 `@assets` 与交付包；6 个源文件全部齐备，页面主样式（皮肤变量、布局、桶/物品、面板、飞行棋/跑酷/消消乐、加载动画、响应式）可正常生效。

2. 字体依赖在线域名 `miaoda.feishu.cn`：离线环境下字体会回退到系统字体。

3. 其他资源均在 `assets/` 内（avatar / items / marks / runner / lib/three.min.js / *.jpg 等），已随项目就位。

4. 目录约定：`index.html` 需与 `styles.css / app.js / data.js / learn.css / learn.js` 同处一层，且该层需包含 `assets/`，`assets/...` 相对路径方可正确解析。
